# OyiEditor

Desktop editor for OyiEngine, written in C# with Avalonia (Windows and macOS). The editor runs in its own process
and talks to a running engine (`oyi serve --rpc`) over TCP with length-prefixed FlatBuffers messages. It depends only
on the OyiProtocol schema, never on engine sources.

中文版：[README.zh-CN.md](README.zh-CN.md)

## Build

Prerequisites: .NET SDK 10 (`global.json` pins the 10.0 feature band). The protocol schema is a git submodule:

```bash
git clone --recurse-submodules https://github.com/OyiGames/OyiEditor.git   # or: git submodule update --init
dotnet build OyiEditor.slnx -c Release
dotnet test --solution OyiEditor.slnx -c Release
dotnet run --project src/OyiEditor.App
dotnet format OyiEditor.slnx --verify-no-changes --exclude protocol src/OyiEditor.Protocol.Schema
```

Set `OYI_EXE` to an engine CLI (`oyi` / `oyi.exe`) to also run the integration tests against a real
`oyi serve --rpc --once`; without it they are skipped.

## Protocol bindings

`protocol/` is [OyiProtocol](https://github.com/OyiGames/OyiProtocol) pinned to a tag. The C# bindings in
`src/OyiEditor.Protocol.Schema/Generated/` are generated by flatc and committed, so building needs no flatc. After
moving the submodule to a new tag, regenerate them with the flatc version the protocol repository pins:

```bash
git -C protocol checkout v1.0.1
python scripts/generate_protocol.py --flatc path/to/flatc
```

CI fails if the committed bindings do not match the schema.

## Layout

```text
protocol/                         OyiProtocol submodule (schema, vendored FlatBuffers C# runtime)
src/OyiEditor.App/                Avalonia application: main window, connection panel, command console
src/OyiEditor.Protocol/           RPC client: framing, envelope codec, RpcClient
src/OyiEditor.Protocol.Schema/    Generated bindings + vendored FlatBuffers runtime (no hand-written code)
tests/OyiEditor.Protocol.Tests/   Client tests against a scripted fake engine, plus the real-engine test
tests/OyiEditor.App.Tests/        Console parsing / formatting and an end-to-end view model test
scripts/generate_protocol.py      Regenerate or check the bindings
```

Package versions are managed centrally in `Directory.Packages.props`; shared compiler settings live in
`Directory.Build.props`.

## Status

Connects to `oyi serve --rpc`: Hello / Welcome handshake (protocol version 1), overlapping requests matched by id,
stream frames, and a console for the engine's commands (`ping`, `version`, `echo -- text`). No world view yet.
